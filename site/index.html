Welcome. This morning, you build your own AI agent

An agent is like a new hire: you give it instructions, tools and experience, then it works for you. By the end of the lab, yours will have produced something real, and this page is where its work shows up.

What you'll do

  1. 01

    Design your agent

    Open Claude Code and say “I want to build my agent”. It interviews you: you answer business questions, it handles all the tooling.

  2. 02

    Create it

    Your agent is born as a simple markdown file, its rulebook, like a new hire’s onboarding pack.

  3. 03

    Run & iterate

    Put it to work on a real task. After each run it asks you 2 questions and records what it learns, so it gets better run after run.

  4. 04

    Showcase

    Its output becomes a polished, Capgemini-branded page, right here, for the final demo.
